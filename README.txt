Прайс-сайт из Excel
===================

Как открыть на компьютере
-------------------------
Откройте файл index.html двойным щелчком.
Интернет и установка программ не нужны.

Как залить на хостинг
---------------------
1. Загрузите на хостинг всю папку целиком:
   index.html
   css/
   js/
   images/
   data/
2. Корневой файл сайта должен быть index.html
   (в панели хостинга это обычно папка public_html или www).
3. PHP, база данных и Node.js не требуются — это обычный статический сайт.

Подходит для Beget, Timeweb, REG.RU, GitHub Pages и большинства обычных хостингов.

Цены на сайте = цена из Excel + 1000 рублей.
